# Observation: The Equalizer (Parity Flip)
- **Key Insight:** The game is a "sum of moves" game. 
- **Normal Play:** First player wins if $\sum a_i \equiv 1 \pmod 2$.
- **Special Move:** This acts as a parity-state reset. If the initial state is a "Losing Position" (Even), Shaunak must transition to a "Winning Position" by leaving Yash with an Even sum ( \times k$).
