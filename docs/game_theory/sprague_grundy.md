# Sprague-Grundy Theorem
The SG theorem states that every impartial game under normal play convention is equivalent to a Nim pile of a certain size (its Grundy value or nim-value).
- **MEX (Minimum Excluded value):** The Grundy value of a state is the smallest non-negative integer that is NOT among the Grundy values of the states reachable in one move.
- **XOR Sum:** If a game consists of independent subgames, the Grundy value of the total game is the XOR sum of the Grundy values of the subgames.
